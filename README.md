# ARDMU

동양미래대학교 구로 캠퍼스의 3D 산책, 건물 외관, 실내 평면도를 모은 프로젝트입니다.

**[웹에서 결과물 열기](https://hoin1357.github.io/ARDMU/)**

| 결과물 | 브라우저에서 열기 |
| --- | --- |
| 전체 캠퍼스 3D와 동그래 산책 | [캠퍼스 산책](https://hoin1357.github.io/ARDMU/동양미래대%20본교%20캠퍼스/캠퍼스%20산책.html) |
| 1호관·도서관·잔디광장 | [외관 3D](https://hoin1357.github.io/ARDMU/1호관과%20도서관%20외관/외관%203D%20보기.html) |
| 층별 실내 구조와 가구 배치 | [실내 평면도](https://hoin1357.github.io/ARDMU/동양미래대%20실내%20구조도.html) |
| 캠퍼스 모형과 현장 사진 비교 | [캠퍼스 순회 대조](https://hoin1357.github.io/ARDMU/동양미래대%20본교%20캠퍼스/캠퍼스%20순회%20대조.html) |

저장소에는 Blender 원본, GLB 모델, 영상과 PDF도 있습니다. 캠퍼스 산책은 처음 열 때 81 MiB인 3D 모델을 불러옵니다.
